# Desafio de Ciencia de Dados: Ativacao de Motoristas

Este repositorio contem o material da aula sobre analise de dados de cadastro e ativacao de motoristas em um app de mobilidade.

> **Aviso:** os dados sao 100% simulados. O exercicio e inspirado no desafio de take-home de ciencia de dados da Uber (cadastro de novos motoristas), amplamente divulgado na internet. A empresa do cenario e um app de mobilidade ficticio: nao ha afiliacao com a Uber, e nenhum numero aqui representa dados reais da empresa ou das cidades citadas.

## Estrutura do Repositorio
- `desafio_uber_analise_completo.ipynb`: O notebook finalizado com todo o codigo e saidas.
- `desafio_uber_analise.ipynb`: O notebook versao estudante (sem saidas) para acompanhar a aula passo a passo.
- `dados/dados_simulados_motoristas.csv`: Os dados simulados (55.000 cadastros de motoristas em janeiro de 2023).

## Como usar
Os notebooks leem o arquivo da pasta `dados/` quando o repositorio foi clonado. Caso contrario (ex.: Google Colab), baixam o mesmo arquivo direto do GitHub com o `pandas`.

## Requisitos
Instale as dependencias usando:
```bash
pip install -r requirements.txt
```
